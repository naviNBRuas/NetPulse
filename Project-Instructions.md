## Project Goal

Develop a functional Internet application that uses network programming to demonstrate, in practice, the fundamental concepts of distributed applications and communication protocols.

The application must allow users or devices to send data periodically to a central or distributed platform.

## Suggested Application Examples

- real-time messaging
- performance dashboards
- laboratory monitoring

## Wireshark Analysis

The project must include a practical stage of traffic capture and analysis using Wireshark.

The group should demonstrate how messages travel through the network, identifying:

- Source and destination IP addresses
- Communication ports used
- Protocols employed (HTTP, TCP, UDP, sockets, and others)
- Message exchange sequence
- Response time
- Retransmissions
- Possible packet losses in UDP communication

Minimum items for the Wireshark analysis:

1. Identification of the developed application protocol
2. Identification of transport- and network-layer protocols
3. TCP handshake analysis, when TCP is used
4. UDP packet analysis, when UDP is used
5. Approximate RTT measurement
6. Packet size identification
7. Client-server communication sequence analysis
8. Comparison between the different communication types implemented
